    Kendali demo

    Geser untuk meniru kondisi lereng. Logika status sama dengan firmware: naik setelah bertahan 2 detik, turun setelah 6 detik.

    SIARENG adalah alat pembelajaran Teknologi IoT, Informatika UNIB. Ambang status masih nilai awal untuk uji, belum berdasarkan kajian geologi, dan alat ini bukan sistem peringatan dini resmi. Untuk keadaan darurat, ikuti arahan BPBD setempat.
