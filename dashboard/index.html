Belum ada data dari alat

Server sudah berjalan, tetapi belum menerima kiriman dari ESP32. Pilih salah satu cara menyambungkannya:

  1. Kabel USB. Colokkan ESP32 ke laptop ini, tutup Serial Monitor, lalu jalankan server dengan SERIAL_PORT=COM5 (sesuaikan nomor port).
  2. WiFi. Di firmware, set KIRIM_WIFI 1 dan isi secrets.h dengan nama WiFi serta alamat laptop ini, lalu upload ulang.
  3. Belum punya alat? Buka mode demo untuk mencoba dashboard dengan data simulasi.

Langkah lengkapnya ada di docs/panduan-pemula.md.

    Kendali demo

    Geser untuk meniru kondisi lereng. Logika status sama dengan firmware: naik setelah bertahan 2 detik, turun setelah 6 detik.

    SIARENG adalah alat pembelajaran Teknologi IoT, Informatika UNIB. Ambang status masih nilai awal untuk uji, belum berdasarkan kajian geologi, dan alat ini bukan sistem peringatan dini resmi. Untuk keadaan darurat, ikuti arahan BPBD setempat.
